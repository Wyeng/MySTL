# C++ 自定义容器实现：MyVector & MyString

## 项目简介

本项目使用 C++ 从零实现两个简化版容器类：`MyVector` 和 `MyString`，用于学习 C++ 动态内存管理、深拷贝、运算符重载及类的生命周期管理。

通过手动管理动态分配的内存，模拟部分标准库容器的核心功能，加深对 C++ 底层机制的理解。

## 项目功能

### 1. MyVector

`MyVector` 是一个简化版的动态数组容器，使用动态数组存储 `int` 类型的数据。

已实现功能：

- **构造函数**：初始化容器状态。

- **拷贝构造函数**：实现深拷贝，避免多个对象共享同一块动态内存。

- **拷贝赋值运算符**：支持对象之间的赋值，并处理自我赋值。

- **析构函数**：释放动态分配的内存。

- **动态扩容**：当容量不足时，重新分配内存并复制已有元素。

- `**push_back()**`：在容器末尾添加元素。

- `**operator[]**`：支持元素访问与修改，并进行下标越界检查。

- **容量与大小查询**：通过 `getSize()` 和 `getCapacity()` 获取当前元素数量与容量。

### 2. MyString

`MyString` 是一个简化版字符串类，使用动态字符数组管理字符串数据。

已实现功能：

- **默认构造函数**：创建空字符串。

- **带参构造函数**：根据 C 风格字符串初始化对象，并检查空指针。

- **拷贝构造函数**：实现深拷贝。

- **拷贝赋值运算符**：支持字符串对象赋值、自我赋值及安全的临时内存管理。

- **析构函数**：释放动态分配的字符数组。

- `**length()**`：获取字符串长度。

- `**Print()**`：输出字符串内容。

- `**operator+**`：实现两个字符串的拼接。

- `**operator==**`：比较两个字符串的内容是否相同。

- `**operator[]**`：访问与修改指定位置的字符，并进行下标越界检查。

## 技术要点

本项目主要练习以下 C++ 知识：

- 类与对象、构造函数和析构函数

- 动态内存分配与释放：`new[]`、`delete[]`

- 裸指针与资源所有权管理

- 深拷贝与浅拷贝

- 拷贝构造函数与拷贝赋值运算符

- Rule of Three（资源管理类的三法则）

- 运算符重载：`operator=`、`operator+`、`operator==`、`operator[]`

- 异常处理：`std::invalid_argument`、`std::out_of_range`

- 智能指针：使用 `std::unique_ptr` 管理临时动态内存

- 动态数组扩容与元素复制

## 学习收获

通过本项目，我进一步理解了：

1. 为什么包含裸指针的类通常需要自行实现深拷贝，避免浅拷贝引发的重复释放等问题。

2. 如何管理动态内存，以及如何通过析构函数释放资源。

3. 拷贝赋值时为什么需要考虑自我赋值和异常安全。

4. 如何通过运算符重载提供更自然的对象操作方式。

5. 如何通过异常处理提高容器接口的安全性。
